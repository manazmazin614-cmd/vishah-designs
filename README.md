# Vishah Design website

This is a simple website for an Indian-wear brand for women. No frameworks or installs are needed.

## Open it in Visual Studio Code

1. Open this folder in Visual Studio Code.
2. Edit `index.html` for the page text, section order, and image links.
3. Edit `styles.css` for colours, fonts, spacing, and the visual design.
4. Edit `products.json` to change product names, colours, and prices.
5. Edit `script.js` for the shopping bag behaviour.
6. Edit `server.js` if you want to change the backend behaviour.

## Run the website

Open the built-in terminal in Visual Studio Code and run:

```bash
npm start
```

Then open `http://localhost:3000` in your browser.

## Add your own images

Put your photos in an `images` folder, then replace an image link in `index.html` with a local path such as:

```html
<img src="images/noor-lehenga.jpg" alt="Noor lehenga set">
```

The current photos are visual placeholders. Replace them with your own campaign and product photography before publishing the site.
